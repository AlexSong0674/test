4. 50종 배지 시안

등급별·카테고리별로 필터링해서 확인할 수 있습니다.

5. 디자이너 산출물 목록

  1. 50종 배지 SVG/PNG (256/512/1024 3종 사이즈)
  2. 4종 프레임 (일반/희귀/특별/프리미어) — 합성 가능한 레이어 분리
  3. 시즌 한정 배지 변형 템플릿 (벚꽃·단풍·눈송이 오버레이)
  4. 배지 잠금 실루엣 버전 (미수집 표시용, 회색조 + 자물쇠 아이콘)
  5. 앱 스토어 / SNS용 4종 대표 배지 (1080×1080) — 마케팅용

7. 라이선스 주의사항

  • AI 생성 이미지는 상업적 사용 가능 여부 확인 (Midjourney Pro 가능, DALL-E 3 OpenAI 가능)
  • 외주 의뢰 시 저작권 양도 명시 (단순 사용권 X)
  • 한국 문화재 모티프는 공공재이나, 특정 박물관 소장 유물은 사진 사용권 확인 필요
