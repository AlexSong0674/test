단계별 성장 전략 및 수익화 계획

Phase 1 — 사용자 기반 확보

0~6개월 · 목표: MAU 10,000명
  • 무료 서비스 운영 (일반 배지 전체 무료)
  • 국내 명소 50→100곳 데이터 구축
  • 배지 수집 데이터 축적 · 앱 안정화

Phase 2 — 구독 모델 도입

6~12개월 · 목표: 구독 전환율 5%
  • 프리미엄 구독 월 2,900원 / 연 24,900원
  • 프리미어 배지 · 광고 제거 · 고급 통계
  • 시즌 한정 배지 · 칭호 시스템 강화

Phase 3 — 굿즈 & B2B 협업

12~24개월 · 목표: MRR 500만 원
  • 한정판 실물 굿즈 (스티커, 엽서, 키링)
  • 지역 관광청 협업 공식 배지 코스
  • 디지털 배지 컬렉션 앱 내 유료 판매

Phase 4 — 여행 콘텐츠 플랫폼

24개월~ · 글로벌 진출 준비
  • 외국인 인바운드 다국어 지원 (영/일/중)
  • 숙소·식당 예약 연결 커미션 수익
  • 여행 크리에이터 콘텐츠 연동

Phase 5 — 여행테크 앱 전환

장기 · 글로벌 여행 플랫폼
  • 해외 배지 확장 (일본 → 동남아 → 유럽)
  • 여행 데이터 기반 광고·인사이트 서비스
  • 글로벌 여행자 커뮤니티
⚖️ 기획서 구성 비교
기존 기획서 vs 수업 발표용 강화 기획서 — 무엇을 보완할까?
항목 기존 기획서 ✨ 강화 방향 (제안)
문제 정의 서비스 배경 나열 수준 강화 페인포인트 구체화 + 시장 규모(TAM/SAM) 수치 추가
경쟁사 분석 ❌ 없음 추가 포켓몬GO, 스탬프투어 앱, 네이버지도 등 직·간접 경쟁 분석
차별화 포인트 핵심 가치 제안 간략히 서술 강화 포지셔닝 맵 + "왜 우리인가?" 명시
MVP 기능 우선순위 P0~P2 표 ✅ 유지 개발 일정(타임라인) Gantt 차트 추가 권장
사용자 여정 텍스트 플로우 서술 강화 이 문서의 시각 다이어그램으로 대체
수익 모델 5단계 로드맵 ✅ 유지 단위경제(유닛 이코노믹스) LTV/CAC 추정 추가
팀 / 실행 계획 ❌ 없음 추가 팀 구성, 역할 분담, 개발 마일스톤
리스크 6개 리스크 표 ✅ 유지 충분함 — 우선순위 정도 추가
기술 스택 비교표 + 추천 조합 ✅ 유지 이 문서의 아키텍처 다이어그램으로 보완
KPI / 지표 부록으로 간략히 강화 본문으로 이동 + North Star Metric 설정
💡 벤처 스타트업 수업 발표용 — 꼭 추가할 3가지
1️⃣
경쟁사 분석 & 포지셔닝

2️⃣
단위 경제 & 재무 모델
CAC, LTV, 손익분기점 예상치 — 수치가 있어야 사업성이 보임
3️⃣
팀 & 실행 로드맵
