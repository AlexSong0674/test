## 🎯 특별·희귀 배지 운영 가이드

### ⭐ 특별 등급 (3곳)
**경복궁 / N서울타워 / 청와대 / 북한산** — 서울을 대표하는 아이콘 랜드마크
- "확인" 팝업 시 풀스크린 컨페티 + 특수 사운드
- 신규 사용자 튜토리얼에서 첫 획득 시도 권장

### 💎 희귀 등급 (9곳)
**창덕궁 / 덕수궁 / 종묘 / 북촌 / 롯데월드타워 / 반포 한강 / 인왕산 / 청계산 / 국립중앙박물관 / 리움 / 노들섬**
- 등급이 높은 만큼 깊이 있는 장소 경험 권장
- "확인" 팝업으로 사용자 의도를 한 번 더 확인

### 데이터 입력 시 주의사항
- 반경(`radius_m`)은 명소 규모에 따라 조정 — 일반적으로 80~250m
- 좌표는 명소 중심부 기준 (정문/대표 지점)
- 실내 명소(박물관·도서관 등)는 반경을 작게(60~100m) 설정
- 자연 명소(산·공원)는 반경을 크게(200~300m) 설정
