핵심 기능

여행을 게임처럼, 기록을 컬렉션처럼

StampGo는 단순한 여행 앱이 아닙니다. 방문한 모든 곳이 나만의 컬렉션이 됩니다.

📍

GPS 자동 인증

여행 모드를 켜면 반경 50~200m 이내 여행지를 자동 감지합니다. 앱을 열고 방문하기만 하면 끝.

🏅

자동 + 확인형 배지

일반 배지는 자동 획득, 희귀·특별 배지는 "확인" 팝업으로 특별함을 살렸습니다. 4가지 등급의 배지를 모으세요.

🏆

랭킹 & 레벨

배지를 모을수록 XP가 쌓이고 레벨이 오릅니다. 전국 순위와 지역 순위에서 다른 여행자들과 경쟁하세요.

🧭

맥락 기반 추천

근처 미수집 배지, 연계 지역 배지, 희귀도 기반 배지를 추천해 다음 여행지를 자연스럽게 유도합니다.

🎖

칭호 시스템

"동네 탐험가"부터 "전설의 여행자"까지. 특정 조건을 달성해야만 얻는 칭호로 차별화된 성취감을 느끼세요.

📤

SNS 공유

희귀 배지를 획득했을 때 한 번의 탭으로 공유. 내 여행 컬렉션을 자랑스럽게 보여주세요.

사용 방법

3단계면 충분합니다

📲

앱 설치 & 가입

카카오 또는 구글 계정으로 30초 안에 시작

🗺

여행 모드 ON

여행을 떠날 때 여행 모드를 켜세요. GPS가 자동으로 작동합니다

🏅

방문 & 배지 획득

명소 반경에 들어서면 인증 팝업이 뜹니다. "인증!" 버튼만 누르면 끝

🎖

모으고 랭킹 도전

배지가 쌓일수록 레벨과 칭호가 업그레이드. 전국 1위를 노려보세요

배지 컬렉션

전국 수백 개의 배지를 모으세요

출시 시 50~100개, 이후 지속 업데이트. 등급별로 다른 희소성과 XP를 제공합니다.

단계별 성장 전략

Phase 1 — 사용자 기반 확보

0~4개월 · 목표 MAU 3,000명
  • 완전 무료 서비스 · 국내 명소 100곳 데이터 구축
  • FlutterFlow + Supabase + 카카오맵 MVP 개발
  • 베타 테스트 → TestFlight 배포

Phase 1.5 — 광고 시범 도입

4~6개월 · 비침습적 네이티브 광고
  • 여행 관련 타겟 광고 (숙소·항공·렌터카)
  • 예상 월 수익 50~150만 원 (MAU 1만 기준)
  • 광고 노출 위치는 UX 해치지 않는 범위 한정

Phase 2 — Voyna+ 구독 도입

6~12개월 · 구독 전환율 5%
  • Voyna+ 월 2,900원 / 연 24,900원
  • 프리미어 배지 · 광고 완전 제거 · 고급 통계
  • 친구 동반 보너스 XP 배율 증가

Phase 3 — 굿즈 & B2B 가맹 배지

12~24개월 · MRR 500만 원
  • 한정판 실물 굿즈 (스티커, 엽서, 키링)
  • 지역 카페·맛집 가맹 배지 시스템 (디지털 스탬프 카드)
  • 지역 관광청 협업 공식 배지 코스

Phase 4 — 글로벌 확장

24개월~ · 외국인 인바운드
  • 영어·일본어·중국어 다국어 지원
  • 한국 관광공사 공식 파트너 배지

Phase 5 — 여행테크 플랫폼

장기 · 글로벌 여행 커뮤니티
  • 해외 배지 확장 (일본 → 동남아 → 유럽)
  • 여행 데이터 기반 광고 인사이트 서비스
