## 1. 공통 디자인 가이드라인

### 1.1 형태 (Shape)
- **기본 형태**: 원형 배지 (1024×1024 정사각형 캔버스, 안전 영역 940×940)
- **외곽**: 등급별 프레임 (아래 1.3 참조)
- **중앙**: 명소를 상징하는 아이콘/실루엣 (전체 면적의 60~70%)
- **하단 라벨**: 명소명 한글 + 영문 (선택, 4~5pt)

### 1.3 등급별 프레임

```
┌─────────────────────────────────────────────────┐
│  등급         외곽 프레임              내부 배경        │
├─────────────────────────────────────────────────┤
│  일반         단색 띠 (회색)            플랫 컬러       │
│  희귀         이중 띠 + 별 ★            그라데이션       │
│  특별         빛나는 광택 + 별 ★★★      펄 텍스처       │
│  프리미어     황금 광택 + 왕관 👑        엠보싱 + 광택   │
└─────────────────────────────────────────────────┘
```

### 1.4 등급별 시각 효과 (앱 내 애니메이션)
| 등급 | 효과 |
|------|------|
| 일반 | 짧은 토스트 (1.5초) |
| 희귀 | 빛나는 별 입자 + 진동 (2초) |
| 특별 | 풀스크린 컨페티 + 특수 사운드 (3초) |
| 프리미어 | 황금 광채 + 왕관 등장 + 화려한 사운드 (3.5초) |

### 1.5 스타일
- **일러스트 톤**: 미니멀 플랫 일러스트 (Notion·Linear 스타일)
- **선 굵기**: 8~12px (1024×1024 기준)
- **그림자**: 부드러운 그림자 (블러 24px, 투명도 15%)
- **타이포**: 한글은 "Pretendard" 또는 "Spoqa Han Sans Neo", 영문은 "Inter"

## 3. 디자이너에게 전달할 작업 명세

### 3.1 산출물 목록
1. **50종 배지 SVG/PNG** (256/512/1024 3종 사이즈)
2. **4종 프레임 (일반/희귀/특별/프리미어)** — 합성 가능한 레이어 분리
3. **시즌 한정 배지 변형 템플릿** (벚꽃·단풍·눈송이 오버레이)
4. **배지 잠금 실루엣 버전** (미수집 표시용, 회색조 + 자물쇠 아이콘)
5. **앱 스토어 / SNS용 4종 대표 배지 (1080×1080)** — 마케팅용

### 3.2 디자인 발주 시 체크리스트
- [ ] 50종 컨셉·컬러·아이콘 확정 (이 문서 기준)
- [ ] 프레임 시안 1차 (등급별 4종) 검토
- [ ] 대표 5종 (경복궁·N서울타워·청와대·북한산·홍대) 풀 디자인 시안
- [ ] 사용자 테스트 → 호감도 확인
- [ ] 50종 전체 양산
- [ ] 잠금 실루엣 버전 자동 생성 스크립트 또는 일괄 작업
- [ ] 시즌 변형 템플릿 1세트

### 3.3 발주 예산 가이드 (참고)
| 옵션 | 단가 | 50종 총액 | 비고 |
|------|------|----------|------|
| Canva 직접 제작 | 무료 | 0원 | 시간 多, 일관성 ↓ |
| 크몽/숨고 외주 (개당) | 3~8만 원 | 150~400만 원 | 표준 옵션 |
| 전문 일러스트레이터 | 10~20만 원 | 500~1,000만 원 | 고품질 |
| AI 일러스트 + 후가공 | 1~3만 원 | 50~150만 원 | 빠르고 저렴, 톤 통일 필요 |

→ **MVP 권장**: AI 일러스트 (Midjourney·DALL-E 3) + Canva 후가공으로 시작 → 사용자 반응 후 외주 업그레이드

### 3.4 라이선스 주의
- AI 생성 이미지는 상업적 사용 가능 여부 확인 (Midjourney Pro 가능, DALL-E 3 OpenAI 가능)
- 외주 의뢰 시 **저작권 양도** 명시 (단순 사용권 X)
- 한국 문화재 모티프는 공공재이나, 특정 박물관 소장 유물은 박물관 사진 사용권 확인 필요
